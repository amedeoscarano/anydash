# Information architecture

## Menu

1. Home
2. Carrier accounts
3. Orders
4. Shipments
5. Customers

Bottom of the sidebar, separated: Settings.

## Settings tree

The Settings entry opens `/settings`, an overview page with one card per settings page. Each card shows an icon, a title and one line, and opens its page.

- General: store details, currency, order defaults
- Team
- Notifications

## Chrome

- Global search in the top bar, Cmd/Ctrl+K (CHR-001, CHR-002).
- Notification bell in the top bar, with an unread count. Its panel lists the last 20 toasts the user saw.
- User menu at the top right: profile, appearance, log out (CHR-008).
- Help entry in the user menu and in the mobile drawer (CHR-011, CHR-012).
